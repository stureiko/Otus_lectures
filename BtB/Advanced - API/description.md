# Интеграция модели с внешним миром - написание API

## ЦА

- разработчика которым необходимо интегрировать решения мл инженеров в прод;
- мл инженеры которые готовят модели к взаимодействию между собой и другими компонентами системы;
- мл инженеры которые хотят разделить решения на компоненты, чтобы уменьшить связанность системы.

Тема важна, для понимания интеграции экспериментов мл инженеров в рабочем Jupyter notebook в рабочий стек используемый на проде.

## Знания вебинара помогут

- интегрировать модели в прод стек;
- автоматически генерировать документацию при обновлении модели;
- проводить валидацию входящих параметров до их передачи в модель;
- повысить безопасность решения за счет предварительного анализа подаваемых в запросе данных;
- настроить авторизацию под каждую модель или модуль системы.

## Чему научатся

### Разработчики

- поймут как решения из Jupyter notebook перенести в виде класса для дальнейшего переиспользования;
- как выделить пакеты для обучения модели и для ее работы на инференсе;
- как настроить проверку данных (каких данных) до передачи в модель;
- как организовать валидацию доступа к модулю модели.

### МЛ инженеры

- поймут как формировать решения для передачи в разработку;
- какие решения используются для интеграции модели из стадии Jupyter notebook в стадию модуль прод системы;
- какие требования предъявляются для оформления модели для автоматического формирования документации;
- как настраивается проверка типов и значения входящих данных.

Вебинар поможет понять и ускорить переход от «экспериментов» к «внедрению решений», повысит безопасность за счет валидации параметров до их передачи в модель, что позволит избежать распространенной атаки на анализ времени исполнения и автоматизировать написание и оформление документации к разработанной модели.
