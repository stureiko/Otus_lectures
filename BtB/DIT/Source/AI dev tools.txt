Программа курса «AI-dev-tools-2025-11».

Модуль 1. «Основы ИИ в разработке».

Описание:

В этом модуле вы научитесь ориентироваться в современных ИИ-инструментах и осознанно выбирать подходящие для разработки. Вы настроете рабочую среду, совместимую ИИ-ассистентами, а также научитесь формулировать промпты для генерации, анализа и отладки кода.Кроме того, вы сможете использовать ИИ для автоматизации рефакторинга, тестирования и документирования, что позволит ускорять процесс разработки и повышать качество создаваемого кода.
	Занятие 1. Введение в AI-разработку.
сравнить ключевые инструменты (Copilot, ChatGPT, Cursor, Qodo, Aider, Windsurf, Code Assist, Continue.dev и др.) по функциональности и подходам (agentic vs. augmented, IDE vs. CLI, RAG)
	Занятие 2. Настройка рабочих сред.
настроить рабочую среду для эффективного использования ИИ-ассистентов в разработке;
	Домашнeе заданиe № 1.
	Генерация простого приложения в IDE.


	Занятие 3. Промпт-инжиниринг и работа с кодом.
формулировать эффективные промпты для генерации, анализа и отладки кода; использовать retrieval‑augmented контекст (Qodo и Continue.dev) для поиска по большим кодовым базам; комбинировать несколько моделей (Cline/Roocode); оценивать ответы ассистентов, корректировать промпты и учитывать ограничения токенов; пользоваться голосовыми запросами через расширения
	Занятие 4. Рефакторинг и тестирование, изучение кода.
использовать ассистентов для автоматического улучшения кода, генерации unit‑ и integration‑тестов, выполнения линтинга и документирования; 
анализировать предложения AI‑инструментов и принимать решения; 
уметь фиксировать изменения в Git и формировать осмысленные commit‑сообщения (Aider);
	Занятие 5. Q&A-сессия.
закрепить навыки работы с ИИ через разбор практических кейсов и ответы на вопросы.

Модуль 2. «ИИ в сопровождении и архитектуре».

Описание:

В этом модуле вы погрузитесь в продвинутые сценарии работы с ИИ в разработке. Научитесь использовать ассистентов для ревью и анализа больших кодовых баз, поиска ошибок и расследования инцидентов. Освоите автоматизацию DevOps-задач, генерацию API и каркасов проектов, а также работу с архитектурными решениями и документацией. В финале модуля вас ждут практические кейсы, которые покажут, как ИИ помогает справляться с реальными задачами в инженерных командах.
	Занятие 6. Онбординг, работа с большим кодом и ревью.
быстро ориентироваться в неизвестных проектах с помощью AI; 
использовать ассистентов, поддерживающих большой контекст;
применять инструменты для автоматического code review
	Домашнeе заданиe № 2.
	Pевью кода opensource проекта.


	Занятие 7. Расследование инцидентов, анализ багов и логов.
использовать AI‑ассистентов для анализа логов и stack trace, генерации гипотез о причинах инцидентов, поиска потенциальных фиксов; 
визуализировать цепочки вызовов с помощью диаграмм; 
применять специализированные средства для генерации гипотез
	Занятие 8. Автоматизация DevOps-задач.
конфигурировать и автоматизировать CI/CD pipelines (GitHub Actions, GitLab, Jenkins); 
автоматизировать миграции и проверки безопасности; 
генерировать диффы и commit‑сообщения
	Занятие 9. Генерация scaffold, boilerplate, API.
uенерировать каркасы проектов, REST API, mock‑сервисы и SDK из текстовых описаний;
использовать prompt‑to‑app инструменты
	Занятие 10. Архитектурные дискуссии, документирование и кодогенерация.
использовать AI‑ассистентов для сравнения архитектурных вариантов и оценки рисков;
 моделировать архитектуру на DSL и генерировать соответствующий код;
 автоматически создавать и обновлять документацию; инструкции для ии в проекте
	Домашнeе заданиe № 3.
	Дополнение проекта инструкциями для ии.


	Занятие 11. Q&A-сессия.
закрепить навыки работы с ИИ через разбор практических кейсов и ответы на вопросы.

Модуль 3. «Расширенные техники и кастомизация».

Описание:

В этом модуле вы освоите работу с большими кодовыми базами и научитесь эффективно использовать ИИ для ревью и навигации по проекту. Вы узнаете, как анализировать баги и логи, строить гипотезы и визуализировать инциденты. Модуль покажет, как автоматизировать DevOps-задачи, генерировать каркасы проектов, API и SDK с помощью ИИ, а также применять ИИ при архитектурных дискуссиях и документировании. В финале вас ждут практические кейсы и QA-сессия, где вы закрепите навыки на реальных инженерных сценариях.
	Занятие 12. Агентные фреймворки.
проектировать и реализовывать простых AI‑агентов на LangChain и OpenInterpreter; 
использовать Continue.dev для создания кастомных агентов в IDE и CI/CD pipelines
	Домашнeе заданиe № 4.
	Минимальный агент на LangChain.


	Занятие 13. Локальные модели и интеграция IDE.

подключать их к IDE (VS Code/Cursor) и внешним сервисам; 
автоматизировать запросы и ответы; 
сравнивать BYO‑model опции для приватности и экономии
	Занятие 14. MCP (Model Context Protocol).
разобраться в принципах MCP и разработать собственный MCP-сервер;
	Домашнeе заданиe № 5.
	Простой MCP-сервер.


	Занятие 15. Подбор инструментов под стек и паттерны внедрения.
оценивать требования разных стеков (backend, frontend, mobile, DevOps), 
сравнивать инструменты по длине контекста, агентским возможностям, цене, BYO‑model поддержке и интеграции с экосистемой (AWS, VS Code, CLI); 
строить матрицу сравнения для ассистентов (Aider, Qodo, Windsurf, Continue.dev, Claude Desktop, Bolt, Amazon Q Developer, Tabnine, CodeMate); 
планировать внедрение на уровне индивидуального разработчика, команды и компании.
	Занятие 16. Code governance и безопасность.
проверять лицензии и политики использования AI‑инструментов;
анализировать безопасность данных и риски утечки; 
управлять API‑ключами и конфиденциальностью
	Занятие 17. Q&A-сессия.
закрепить навыки работы с ИИ через разбор практических кейсов и ответы на вопросы.
