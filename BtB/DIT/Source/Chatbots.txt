Программа курса «Chatbots-2025-11».

Модуль 1. «Основы и базовая архитектура».

Описание:
В этом модуле вы познакомитесь с видами ассистентов и ботами 2025 года. Разберёте базовую архитектуру систем: интерфейс, ядро, инструменты, память. Узнаете, какие каналы бывают (Telegram, VK, Web, голос) и где они применяются. Освоите основы архитектурного мышления для построения диалоговых систем.
	Занятие 1. Обзор ботов, голосовых ассистентов и ИИ-агентов.
познакомиться с курсом, командой и друг другом; 
рассмотреть примеры ассистентов; 
рассмотреть сильные и слабые стороны разных каналов и их применение в бизнесе.
	Занятие 2. Инструменты разработки и архитектура диалоговых систем.
научиться устанавливать Python и настраивать проект; 
познакомиться с репозиторием и библиотеками; 
рассмотреть, как устроена архитектура бота и где хранятся конфигурации.
	Занятие 3. Asyncio, async/await, event loop // ДЗ.
научиться работать с асинхронным кодом;
научиться создавать параллельные запросы и избегать ошибок при работе с I/O.
	Домашнeе заданиe № 1.
	Каркас + mini-async парсер.
Создать репозиторий с базовой структурой и написать короткий асинхронный скрипт, который параллельно обращается к нескольким публичным HTTP-эндпоинтам.

Модуль 2. «Создание Telegram-бота на aiogram».

Описание:
В этом модуле вы изучите основы работы с библиотекой aiogram. Научитесь создавать простые боты, обрабатывать команды и сообщения, подключать клавиатуры и меню. А также освоите FSM для сложных сценариев и организацию структуры кода. В конце модуля соберёте мини-проект.
	Занятие 4. Введение в aiogram.
научиться регистрировать бота в BotFather;
научиться создавать эхо-бота;
изучить базовую обработку команд и медиа.
	Занятие 5. Клавиатуры и простое меню.
научиться использовать Reply- и Inline- клавиатуры;
научиться строить простые меню и реализовать минимальную навигацию.
	Занятие 6. FSM: многошаговые сценарии.
изучить механику состояний;
научиться создавать анкеты/опросы и сохранять промежуточные данные.
	Занятие 7. Структура кода и мини-проект // ДЗ.
научиться организовывать проект по модулям;
научиться реализовывать централизованную обработку ошибок;
научиться собирать инфо-бота.
	Домашнeе заданиe № 2.
	Эхо-бот с меню и мини-анкетой (FSM).

Собрать простого бота: команды, плоское меню, двухшаговая анкета на MemoryStorage, базовое логирование aiogram.

Описание:
Этот модуль посвящён хранению и обработке данных. Вы освоите основы SQL и SQLite, затем перейдёте к работе с ORM. Научитесь подключать БД в aiogram, сохранять историю и профили пользователей. В завершении разберёте миграции и оптимизацию запросов.
	Занятие 8. SQLite и основы SQL.
научиться создавать таблицы;
научиться выполнять базовые SQL-команды и сохранять историю обращений.
	Занятие 9. SQLAlchemy (ORM) без боли.
изучить базовую работу с ORM;
научиться создавать модели и использовать слой репозиториев.
	Занятие 10. Интеграция БД в бота.
научиться подключать базу к aiogram, сохранять данные пользователей и анкет, обрабатывать ошибки.
	Занятие 11. Миграции и данные // ДЗ.
научиться использовать Alembic для обновления схемы и работать с seed-данными.
	Домашнeе заданиe № 3.
	БД + ORM: сохраняем анкету и показываем историю.
Подключить БД, описать модели ORM (SQLAlchemy), сохранять итоги анкеты в БД и показывать последние сообщения.

В этом модуле вы узнаете, чем webhook отличается от long polling и как использовать FastAPI для их настройки. Освоите базовую инфраструктуру с Docker и docker-compose. А также научитесь запускать бота в изолированном окружении и готовить проект к продакшену.
	Занятие 12. Webhook на FastAPI.
изучить отличия long polling и webhook;
научиться настраивать вебхуки и health-check.
	Занятие 13. Docker и docker-compose (локальная инфраструктура) // ДЗ.
научиться собирать контейнеры для бота и БД;
научиться подключать переменные окружения и запускать стек локально.
	Домашнeе заданиe № 4.
	Локальный запуск по Webhook + Docker Compose.
Перевести бота на Webhook через FastAPI-маршрут и запустить локально в Docker Compose (бот + БД).

Модуль 7. «RAG: поиск по документам и ссылки на источники».

Описание:
Этот модуль посвящён Retrieval-Augmented Generation. Вы научитесь создавать поиск по документам и добавлять ссылки на источники в ответы. Освоите работу с Qdrant и метрики качества. На практике соберёте первый RAG для Telegram-бота.
	Занятие 19. Основы RAG (без векторной БД).
научиться проводить простейший поиск по текстам и собирать ответы с цитатами.
	Занятие 20. Векторный поиск с Qdrant.
научиться устанавливать Qdrant, настраивать эмбеддинги и интегрировать поиск в Telegram-бота.
	Занятие 21. Качество и устойчивость RAG // ДЗ.
научиться внедрять fallback-логику, проверку источников и метрики качества.
	Домашнeе заданиe № 7.
	/askdoc: RAG-лайт + Qdrant-поиск (top-k).

Сделать команду /askdoc <вопрос>: сначала простой keyword-поиск по локальному FAQ, затем векторный поиск в Qdrant; ответить с цитатой.
