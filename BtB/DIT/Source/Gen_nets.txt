Программа курса "Нейросети длягенерациивизуальногоконтента"

Модуль 1 "Введение в компьютерное зрение"

Основы глубокого обучения. Матрицы. Основы Python.
- познакомиться с историей и основными концепциями нейронных сетей;
- развить практические навыки базового программирования для ихреализации.

Основы глубокого обучения
- изучить ключевые аспекты обучения (оптимизации) нейронныхсетей;
- освоить навыки их реализации с использованием Pytorch.

Сверточные нейронные сети
- сформировать комплексное понимание компьютерного зрения исверточных нейронных сетей (CNN);
- развить практические навыки их реализации в Pytorch

Классические архитектуры нейронных сетей
- познакомиться с ведущими архитектурами нейронных сетей для классификации изображений, методом переноса знаний;
- развить практические навыки работы с предобученными моделями;

Работа с набором данных
- познакомиться с различными типами наборов данных для работы сизображениями;
- рассмотреть методы аугментации и разметки данных, которые в дальнейшем потребуются для обучений нейронных сетей;

Сегментация изображений
- познакомиться с задачей сегментации изображений;
- изучить архитектуру U-Net;
- рассмотреть практическое применение модели Segment Anything(SAM);

Модуль 2. Базовые порождающие модели

Порождающие модели
- провести глубокое изучение задачи генерации изображений;
- познакомиться с различными типами порождающих моделей;
- рассмотреть, как эти модели могут быть использованы для создания новых, реалистичных изображений, и как оценивать качество генерации;

Генеративно-состязательные сети
- изучить теорию и практику работы с генеративно-состязательными сетями (GAN);
- освоить методы условной генерации изображений;
- рассмотреть основные принципы, виды GAN и возможности их применения для создания контента;

Семейство моделей StyleGAN
- познакомиться с принципами работы и архитектурой генеративно-состязательных сетей (GAN) на примере StyleGAN;
- попрактиковаться в интерполяции и манипуляции изображениями;

Вариационный автокодировщик
- освоить теоретические основы и практические навыки работы с автокодировщиками и вариационными автокодировщиками (VAE);
- изучить принцип квантизации векторов и моделей VQ-VAE;

Модуль 3. Современные порождающие модели

Архитектура трансформер
- понять основные принципы и компоненты архитектурытрансформера;
- освоить навыки работы с трансформерами для классификации изображений;

Авторегрессионная генерация изображений
- освоить методы авторегрессионной генерации изображений и навыки работы с трансформерами для генерации изображений;

Диффузионные нейронные сети
- изучить принципы работы диффузионных нейронных сетей;
- освоить навык генерации изображений с помощью современных диффузионных сетей;

Контролируемая генерацияи зображений с помощью диффузионных нейронных сетей
- на практике научиться контролировать процесс генерации изображений с использованием диффузионных моделей;

Дообучение диффузионных моделей
- получить навыки дообучения диффузионных моделей для специфических задач;

Модуль 4.  Генерация по тексту

Классические методы генерации изображений по тексту
- изучить традиционные подходы к генерации изображений на основетекстового описания;
- освоить навык запуска генерации изображений по тексту с помощью GAN;

Современные методы генерации изображений потексту
- освоить передовые технологии создания изображений из текстовых описаний;
- освоить навык генерации изображений по тексту;

Оценка качества генерации изображений
- научиться оценивать и сравнивать качество генерированных изображений;
- освоить навык программного сравнения изображений;

Generative Video Models: Stable Video Diffusion, Gen2, MAKE-A-VIDEO
- рассмотреть подходы к генерации видео на основе диффузионных моделей;
- изучить модели генерации видео Stable Video Diffusion, Gen2, MAKE-A-VIDEO;

Генерация сцены в 3D
- овладеть методами создания трехмерных сцен и объектов;

Модуль 5. Задачи генерации изображений

Трансляция изображения в изображение
- изучить методы и алгоритмы, позволяющие преобразовывать одно изображение в другое, сохраняя при этом ключевые характеристики исходного изображения;

Генерация изображения по сегментации
- освоить техники генерации реалистичных изображений на основекарт сегментации;
- научиться обучать нейронные сети интерпретировать и воспроизводить текстуры и объекты;

Нейронный перенос стиля
- понять принципы и освоить практические навыки переноса стиля одного изображения на другое, с помощью глубоких нейронных сетей;

Генерация векторных изображений
- изучить методы создания векторных изображений, которые могут масштабироваться без потери качества, и практическое применение этих методов;

Гармонизация изображения
- научиться методам гармонизации элементов изображения, чтобы они выглядели естественно в составе общей композиции, например: при комбинировании объектов из разных источников;
