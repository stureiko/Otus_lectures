Модуль 1. «Python для работы с текстами».

Описание:
Вводный модуль, посвященный повторению основных методов работы с данными в Python и работе с текстами. В модуле также рассмотрены методы парсинга данных и методы работы с регулярными выражениями — необходимые навыки в NLP.
	Занятие 1. Введение в NLP.
рассмотреть область Natural Language Processing;
рассмотреть задачи NLP;
обсудить современные достижения в области NLP.
	Занятие 2. Recap python/ data analysis/ визуализации.
вспомнить основы работы с Python для анализа данных и визуализации;
поработать с библиотеками pandas, numpy, matplotlib, seaborn.
	Занятие 3. Работа со строками + регулярные выражения.
рассмотреть методы работы со строками;
освоить работу с регулярными выражениями.
	Занятие 4. Парсинг данных.
рассмотреть открытые источники данных;
использовать API, парсинг;
создать свои датасеты.
	Домашнeе заданиe № 1.
	Откуда берутся датасеты.
По аналогии с занятием по парсингу данных, возьмите интересующий вас сайт, на котором можно пособирать какие-то данные (и при этом API не предоставляется). 
<br>Идеальный датасет должен иметь текстовое описание некоторого объекта и некоторую целевую переменную, соответствующую этому объекту. Например:
- Сайт новостей: текстовое описание — сама новость, целевая переменная — количество просмотров новости (можно поделить на число дней с момента даты публикации, чтобы получить «среднее число просмотров в день»).
- Сайт с товарами/книгами/фильмами: текстовое описание товара/книги/фильма + средний рейтинг в качестве целевой переменной.
- Блоги — тексты заметок + число просмотров.
- И любые другие ваши идеи, которые подходят под такой формат. 
Напишите свой парсер, который будет бегать по страничкам и автоматически что-то собирать. 
Не забывайте, что парсинг — это ответственное мероприятие, поэтому не бомбардируйте несчастные сайты слишком частыми запросами (можно ограничить число запросов в секунду при помощи time.sleep(0.3), вставленного в теле цикла).

<br>

При необходимости очистить датасет от мусора с помощью регулярных выражений.
<br>Посчитать статистики по собранным данным и провести EDA собранных данных (в случае, если данные представляют собой текст — посчитать частотности слов, выявить наиболее частотные слова и т. п.).

<br>

Не забудьте сохранить полученный датасет, он вам еще пригодится в дальнейших домашних заданиях.

Модуль 2. «Введение в DL».

Описание:
Вводный модуль по Deep Learning. Данный модуль дает общее представление о нейронных сетях, фокусируясь на методах и архитектурах, востребованных в NLP.
	Занятие 5. Введение в нейросети.
познакомиться с моделью искусственного нейрона;
булевы операции над нейроном;
разобрать как устроена нейронная сеть.
	Занятие 6. Градиентный спуск и backpropagation.
вспомнить, что такое градиентный спуск;
повторить правило цепочки производных;
рассмотреть алгоритм backpropagation;
понять, как нейронная сеть обучается.
	Занятие 7. PyTorch. Часть 1.
познакомиться с фреймворком для глубокого обучения PyTorch и его архитектурой;
разобраться, как устроены тензоры, какие операции над ними поддерживаются;
изучить, как работать с данными в PyTorch, как использовать объекты dataset и dataloader;
создать свою нейронную сеть, и обучить ее решать задачу классификации рукописных цифр на примере датасета MNIST.
	Домашнeе заданиe № 2.
	Практика по PyTorch.
Задание:
1) Используя PyTorch, создать и обучить регрессионную модель, которая аппроксимирует значение функции sin(x + 2*y)*exp(-(2*x + y)^2) на диапазоне значений [-10; 10] по х и у.
2) В качестве обучающей выборки необходимо сгенерировать 20000 точек случайным образом.
3) Разделить получившийся датасет на train / test / val в отношениях 70% / 15% / 15%, соответственно.

<br>

Результаты:
a) Посчитать метрику Mean Square Error (MSE) на test.
b) Нарисовать график, в котором сравнивается истинная функция и ее аппроксимированный вариант (предсказываемый моделью).

	Занятие 8. PyTorch. Часть 2.
углубиться в PyTorch, и рассмотреть отличия версии 2.x от 1.x;
кратко пройтись по его модулям;
проверить на примерах компиляцию моделей torch.compile(), и убедиться, действительно ли PyTorch 2.x работает быстрее 1.x;
на примере MNIST / CIFAR рассмотреть другие архитектуры сетей (CNN);
попробовать также Transfer Learning: MNIST -> CIFAR -> MNIST;
обучить нейросеть задаче регрессии.
	Занятие 9. Рекуррентные сети. Часть 1.
разобрать, что такое рекуррентная нейронная сеть;
познакомиться с видами рекуррентных сетей.
	Занятие 10. Рекуррентные сети. Часть 2.
рассмотреть классификацию и генерацию текста рекуррентной сетью.

В нем изучаются архитектура Transformer, механизмы transfer learning, модель BERT и работа с предобученными языковыми моделями. Рассматриваются задачи именованного распознавания сущностей (NER), генеративные языковые модели, а также подходы к промптингу и использование LLM в диалоговых системах.
	Занятие 14. Архитектура Transformer.
рассмотреть архитектуру Transformer;
познакомиться с идеей self-attention mechanism.
	Занятие 15. Transfer learning; BERT model.
познакомиться с идеей transfer learning и идеей pretraining+finetuning подхода для решения NLP задач;
изучить модель BERT.
	Занятие 16. Работа с предобученными языковыми моделями. Задача NER.
рассмотреть задачу NER и области ее применения;
научиться на практике дообучать языковые модели для различных задач.
	Домашнeе заданиe № 3.
	Почувствуй мощь трансформеров в бою.
В качестве данных выберете возьмите датасет RuCoLA для русского языка https://github.com/RussianNLP/RuCoLA (в качестве train возьмите in_domain_train.csv, а в качестве теста in_domain_dev.csv). <br>
Разбейте in_domain_train на train и val. <br>
Зафайнтьюньте и протестируйте RuBert или RuRoBerta на данной задаче (можно взять любую предобученную модель руберт с сайта huggingface. Например, ruBert-base/large https://huggingface.co/sberbank-ai/ruBert-base / https://huggingface.co/sberbank-ai/ruBert-large или rubert-base-cased https://huggingface.co/DeepPavlov/rubert-base-cased, ruRoberta-large https://huggingface.co/sberbank-ai/ruRoberta-large, xlm-roberta-base https://huggingface.co/xlm-roberta-base).

<br>

Возьмите RuGPT3 base или large и решите данное задание с помощью методов few-/zero-shot. <br>
а) переберите несколько вариантов затравок; <br>
б) протестируйте различное число few-shot примеров (0, 1, 2, 4).
<br>Обучите и протестируйте модель RuT5 на данной задаче (пример finetun’а можете найти здесь https://github.com/RussianNLP/RuCoLA/blob/main/baselines/finetune_t5.py). <br>
Сравните полученные результаты.

	Занятие 17. Генеративные языковые модели и энкодер-декодер архитектуры.
рассмотреть модель GPT3 и концепцию few-/zero-shot learning и архитектуру T5.
