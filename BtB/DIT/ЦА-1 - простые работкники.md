# «Практическое использование ИИ в повседневных задачах» (30 занятий / 5 модулей)

Учебная программа на 30 занятий (5 модулей) для рядовых сотрудников крупной государственной организации, которым нужно использовать ИИ в ежедневных рабочих задачах: подготовка документов, поиск информации, анализ данных, автоматизация рутины, взаимодействие с гражданами/клиентами, работа с внутренними регламентами и сервисами.

Программа создана на основе профессиональных курсов Отус (AI-Architect, AI-Dev-Tools, Chatbots, GenAI/Vision, LLM-Deep Dive, MLOps, NLP Advanced, NLP Base, AI/ML Product Management).

Программа НЕ техническая. Сотрудникам не нужно программировать, реализовывать модели, писать код — только использовать ИИ-инструменты безопасно, корректно и эффективно.

## Сотрудники научатся

- грамотно и безопасно использовать ИИ в задачах компании;
- писать структурированные запросы;
- создавать документы, презентации, отчёты быстрее;
- работать с информацией гораздо эффективнее;
- автоматизировать рутину без ИТ-отдела.

## Руководство получит

- рост производительности;
- снижение нагрузки на сотрудников;
- улучшение качества коммуникации с гражданами и клиентами;
- снижение ошибок и повышение скорости обработки информации.

## Модуль 1. Основы ИИ и цифровой грамотности сотрудников (6 занятий)

Цель: дать простое понимание, что такое ИИ, чего от него можно ждать, где он помогает, где нет.

1. Что такое современный ИИ и где он используется

   - Базовые определения (что такое LLM, генеративный ИИ).
   - Примеры в госсекторе: поиск информации, составление документов, автоматизация обращений.
   - Возможности и ограничения.

2. Инструменты ИИ: ChatGPT, YandexGPT, Copilot и др. (без углубления в техническую часть)

   - Обзор ассистентов из AI-Dev-Tools  ￼ (адаптация — без IDE).
   - Где сотруднику уместно применять ассистентов, а где — нет.

3. Промпт-гигиена: как правильно формулировать запросы

    – Чёткие роли, контекст, формат ответа.
    – Примеры хороших и плохих формулировок.
    – Шаблоны подсказок.

4. Юридические, этические и ИБ-ограничения работы с ИИ

    – Что можно отправлять модели, а что запрещено.
    – Риски галлюцинаций и способы контролировать ответы.

5. Ошибки ИИ и как с ними работать

    – Основано на подходах оценки качества в LLM-DD и NLP-Adv.
    – Проверка фактов, альтернативные запросы, перекрёстная проверка.

6. Практикум: решаем реальные задачи сотрудников с помощью ИИ

    – Написание писем, отчётов, резюме обращений, саммари совещаний.
    – Упражнения из реальных процессов госкомпании.

## Модуль 2. Использование ИИ в офисных задачах (6 занятий)

Цель: научить применять ИИ в ежедневных рабочих процессах без программирования.

1. ИИ для работы с документами

    - Редактирование, улучшение стиля, унификация форматов.
    - Генерация шаблонов, титульных страниц, актов, писем.

2. ИИ для анализа текстовой информации

   - Суммаризация длинных текстов (на основе техник из NLP-Adv).
   - Выделение ключевых пунктов.
   - Создание конспектов/выжимок.

3. ИИ для работы с большими объёмами информации

   - Поиск ответов по документам и регламентам.
   - Использование RAG-подходов в прикладном формате (не технич.) из AI-Architect  ￼.

4. ИИ для Excel/таблиц/отчётов

   - Генерация формул.
   - Автоматический анализ данных.
   - Построение текстовых интерпретаций графиков.

5. ИИ для автоматизации рутины

   - Автоматизация переписок.
   - Генерация инструкций и алгоритмов действий.
   - Создание чек-листов и памяток.

6. Практикум: автоматизация рабочего дня с помощью ИИ

   - Практикические кейсы на примерах сотрудников.

## Модуль 3. Коммуникации и чат-боты для сотрудников (6 занятий)

Цель: научить сотрудников использовать ИИ для коммуникаций — обращения граждан, ответы на вопросы, чат-боты, голосовые ассистенты.

1. Что такое чат-боты и ассистенты

   - Базовые подходы из курса Chatbots (упрощённо).
   - Где боты полезны в госкомпаниях.

2. Как использовать ИИ для подготовки ответов гражданам, клиентам, партнёрам

   - Улучшение тона, корректность, официально-деловой стиль.
   - Создание шаблонов ответа.

3. ИИ для внутренних коммуникаций

   - Ответы на вопросы сотрудников.
   - Создание инструкций и справок.
   - Помощь в разъяснении регламентов.

4. Как правильно писать запросы для подготовки автоматизированных ответов

   - Системные промпты, роли, ограничения.

5. Безопасность и контроль качества автоматических ответов

   - Галлюцинации.
   - Тон сообщений.
   - Юридические ограничения (на основе AI-PM).

6. Практикум: создаём мини-бота для отдела без программирования

   - Использование готовых no-code инструментов.

## Модуль 4. Генеративный контент: документы, изображения, презентации (6 занятий)

Цель: дать навыки создания материалов, необходимых сотрудникам: презентации, инфографика, изображения, макеты, видео.

1. Введение в генеративные модели изображений

   - Основано на курсе по генерации визуального контента, но в сильно упрощённой форме.
   - Какие модели бывают и что они умеют.

2. Создание презентаций с помощью ИИ

   - Генерация структуры, дизайна, текстов.
   - Автоматическое оформление слайдов.

3. Генерация изображений под рабочие задачи

   - Инфографика, схемы, иконки.
   - Корпоративный стиль.

4. Создание иллюстраций для внутренних материалов

   - Безопасное использование.
   - Проверка соответствия корпоративным требованиям.

5. Видео- и аудио-генерация

   - Озвучка документов.
   - Создание коротких видеороликов для инструкций/обучения.

6. Практикум: «От текста к презентации и далее к иллюстрациям»

   - Полный цикл за одно занятие.

## Модуль 5. Эффективность сотрудника с ИИ и внедрение в отделы (6 занятий)

Цель: выстроить практическое использование ИИ в подразделениях компании.

1. Как встроить ИИ в рабочие процессы подразделения

   - Базируется на AI-PM блоках по бизнес-ценности и процессам.
   - Какие задачи подходят, какие нет.
   - Как определять эффект.

2. Оценка выгод: где ИИ экономит время и ресурсы

   - На основе принципов ML-PM: KPI, метрики, эффективность PoC.
   - Измерение конкретных эффектов: время обработки, число ошибок.

3. Как правильно ставить задачу ИИ

   - Контекст, цель, входные данные, ограничения.
   - Практика постановки задач.

4. Как строить безопасную работу с ИИ внутри компании

   - Журналирование, хранение данных, черные списки тем.
   - Общие правила поведения сотрудников.

5. Практикум: разрабатываем ИИ-решение для своего отдела (без технической реализации)

   - Разбор 3–5 типовых сценариев: канцелярия, HR, закупки, клиентский сервис, аналитика.

6. Итоговая аттестация + демонстрация кейсов.
