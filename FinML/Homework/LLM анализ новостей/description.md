# Задание

## 1. Загрузка и использование предобученной модели FinBERT

- Загрузить и установить модель FinBERT с HuggingFace
- Провести анализ тональности новостных заголовков или текстов (позитивная, негативная, нейтральная)
- Построить распределение тональностей по времени для выбранных тикеров

## 2. Подготовка рыночных данных

- Выбрать минимум 2 финансовых инструмента (например, акции компаний или криптовалюты)
- Загрузить исторические данные по ценам (OHLCV)
- Загрузить период новостей
- Рассчитать целевую переменную: направление движения цены на следующий день/час
  
## 3. Интеграция новостного фона в прогнозную модель

- Для каждого временного интервала (день или час) агрегировать оценки тональности новостей (например, среднее значение тональности или долю позитивных/негативных новостей).
- Объединить полученные признаки с рыночными данными.

## 4. Прогноз направления движения котировок

- Загрузить с HuggingFace любую другую предобученную модель для классификации текстов и дообучить её на связке “новость → направление движения котировок выбранного фин инструмента”
- Сравнить результаты двух подходов:

  - Использование только тональности FinBERT как признака.
  - Использование дообученной модели HuggingFace напрямую для предсказания направления движения котировок.

## 5. Оценка качества моделей

- Проведите обратное тестирование на исторических данных предыдущей модели и модели с учетом тональности новостей
- Дообученная на конкретых примерах модель показала лучшее или худшее качество и почему?
