# Задание

## 1. Выбор финансовых инструментов и данных

- Выберите минимум 2 торговых инструмента (акции, валютные пары, криптовалюты)
- Загрузите исторические данные (OHLCV) за не менее чем 6 месяцев.
- Определите целевую переменную: направление движения цены на следующий шаг.

## 2. Подготовка данных

- Постройте лаговые признаки (цены за предыдущие N шагов, индикаторы, например SMA, RSI).
- Нормализуйте данные для подачи в модель.
- Разделите данные на train/validation/test.

## 3. Использование предобученной трансформерной модели

- Найдите и загрузите с HuggingFace предобученную трансформерную модель для временных рядов (например, TimesNet, Informer, DLinear).
- Адаптируйте её для задачи бинарной классификации (рост/падение).

## 4. Дообучение модели на ваших данных

- Проведите fine-tuning модели на подготовленных данных.
- Настройте гиперпараметры (длина окна, размер батча, learning rate).

## 5. Обогащение данных

- Воспользуйтесь подготовленными вами ранее данными технического анализа и обогатите пространство признаков вашей модели
- Дообучите модель на новых данных
- Проведите обратное тестирование качества модели на исторических данных
