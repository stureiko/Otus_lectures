# Требования

## База ML

- Опыт разработки на Python;
- Навыки разработки и оптимизации ETL процессов;
- Опыт работы с классическими ML моделями;
- Зазворачивание моделей в виде контейнеров в Яндекс облаке;
- Настройка мониторинга моделей Prometheus+Grafana;
- Настройка алертинга моделей.
  
## Специфика курса

- Понимание основных задач построения торговой стратегии;
- Понимание принципов технического анализа и занние библиотеки TaLib;
- Знать теорию портфельной оптимизации (как минимум Марковица);
- Знать библиотеки обратного тестирования Backtesting/Backtrader, быть готовым дать ОС студентам по обоим;
- Построение ансамблей методами sklearn.pipeline;
- Уметь оценивать риски инвестиционного портфеля.

## Специфика тематическая

- Классический ML в задаче торговой стратегии. Построить модель, протестировать, показать слабые стороны;
- Глубокие модели. Показать подход "в тупую", построение сетки для пронозирования цен;
- Применение RL, библиотека FinRL, ElegantRL или что-то похожее;
- Применение LLM для анализа новостей и встраивание этой модели в ансамбль; FinBERT;

## Специфика применения

- Знать возможности API московской биржи и российских брокеров. Готов продемонстрировать пример получения данных с Мосбиржи и/или какого-либо российского брокера;
- Знать и продемонстрировать скачивание данных по крипте;
- Знать специфику взаимодействия моделей с российскими брокерами для выктки моделей в стадию прода;
- Разворачивание модели в виде контейнера в Яндекс облаке и связь ее с брокерской площадкой;
