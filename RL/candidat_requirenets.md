# Требования

## Преподаватель

### База ML

- Опыт разработки на Python;
- Навыки разработки и оптимизации ETL процессов;
- Опыт работы с классическими ML моделями;
- Построение полносвязных нейросетей на PyTorch или TensorFlow.
  
### Специфика курса

- Марковский процесс принятия решений - что это;
- Базовая теория RL - построение кастомной среды на базе gym;
- Классические модели RL - PG, SARSA, Q-learning;
- DQN;
- Actor-Critic, A2C;
- DDPG, TD3, PPO;
- Мультиагенты, частично-наблюдаемые среды;
- Применение RL (где-то) (игры/роботы/рекомендации/ тестирование) - любой практический пример применения в практике;
- UNITY - может создать среду и сделать пример взаимодействия агента с вирутальным миром.
