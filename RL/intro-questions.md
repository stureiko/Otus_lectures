# Обучение с подкреплением

1. Какое ключевое отличие обучения с подкреплением от других типов машинного обучения?  
   - a) Оно основано на обучении по размеченным данным  
   - b) Оно использует механизм проб и ошибок для взаимодействия с окружающей средой ✅  
   - c) Оно строит прогнозы, анализируя исторические временные ряды  

2. Какие элементы входят в состав Марковского процесса принятия решений (MDP)?  
   - a) Агент, состояния, действия, вознаграждение, функция перехода ✅  
   - b) Обучающая выборка, тестовая выборка, целевая переменная  
   - c) Гиперпараметры, модель, функция потерь  

3. Какова основная цель функции ценности (value function) в обучении с подкреплением?  
   - a) Оценивать, насколько выгодно выполнить определенные действия в данном состоянии
   - b) Предсказывать суммарную награду на основе текущего состояния  ✅  
   - c) Оценивать вероятность ошибки модели в зависимости от входных данных  

4. Чем отличается SARSA от Q-learning?  
   - a) SARSA использует жадную стратегию, а Q-learning – случайный выбор действий  
   - b) SARSA обновляет значения на основе реального действия, а Q-learning – на основе наилучшего возможного ✅  
   - c) В SARSA обновление значений основано на глубоком обучении, а в Q-learning – на линейной регрессии  

5. Какова основная идея метода Policy Gradient?  
   - a) Оптимизация функции ценности с помощью градиентного спуска  
   - b) Оптимизация политики агента напрямую, без необходимости вычисления функции ценности ✅  
   - c) Использование алгоритмов эволюции для выбора лучшей политики  

6. Зачем используются глубокие нейронные сети в обучении с подкреплением?  
   - a) Они позволяют агенту быстрее находить оптимальные действия за счет запоминания состояний  
   - b) Они помогают эффективно аппроксимировать сложные функции ценности и политики ✅  
   - c) Они используются только для увеличения производительности вычислений  

7. Какова основная роль механизма experience replay в Deep Q-Network (DQN)?  
   - a) Он позволяет агенту хранить и повторно использовать прошлый опыт для стабилизации обучения ✅  
   - b) Он отвечает за прогнозирование будущего состояния на основе текущего действия  
   - c) Он используется для ускорения обучения путем параллельной обработки данных  

8. Чем различаются value-based и policy-based методы в обучении с подкреплением?  
   - a) Value-based методы работает с q-функцией, а policy-based со стратегией действий ✅  
   - b) Value-based методы работают только с дискретными действиями, а policy-based – только с непрерывными  
   - c) Value-based методы основаны на случайном выборе действий, а policy-based – на градиентных методах оптимизации  

9. Какую роль выполняют актор и критик в алгоритмах Actor-Critic?  
   - a) Актор принимает решения о действиях, а критик оценивает их качество ✅  
   - b) Актор оценивает состояние, а критик выбирает лучшее действие  
   - c) Актор обновляет функцию вознаграждения, а критик обучает нейросеть агента  

10. Что является ключевой идеей алгоритма Proximal Policy Optimization (PPO)?
   - a) Использование ограниченного обновления политики для повышения стабильности обучения ✅
   - b) Обновление политики на основе матрицы Фишера  
   - c) Применение эволюционных алгоритмов для поиска оптимального решения  

11. Какой фактор отличает Twin Delayed DDPG (TD3) от Deep Deterministic Policy Gradient (DDPG)?  
   - a) TD3 использует две Q-сети для уменьшения переоценки значений действий ✅  
   - b) TD3 применяет рекуррентные нейронные сети вместо полносвязных  
   - c) TD3 работает только с дискретными пространствами действий  

12. Как использование LSTM может улучшить алгоритмы обучения с подкреплением?  
   - a) Позволяет агенту учитывать зависимость состояний во времени и работать с частично наблюдаемыми средами ✅  
   - b) Уменьшает потребление памяти за счет сжатия представлений состояний
   - c) Используется исключительно для обработки временных рядов в обучении с подкреплением
